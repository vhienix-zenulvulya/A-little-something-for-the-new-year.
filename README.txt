NEW YEAR LETTER FOR YURI

To add your own music:
1. Put your MP3 file in this same folder, beside index.html.
2. Rename the MP3 file to: song.mp3
3. Open index.html in a browser to test it.
4. To publish it with GitHub Pages, upload index.html, style.css, app.js, and song.mp3 to the same folder in your repository.

The Play the song button plays the local song.mp3 file on the page. It does not open YouTube.

You can edit the letter text in index.html.
